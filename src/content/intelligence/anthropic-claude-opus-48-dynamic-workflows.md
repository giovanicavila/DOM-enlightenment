Anthropic released Claude Opus 4.8 on May 28, 2026, immediately claiming the #1 spot on the Artificial Analysis Intelligence Index at 61 — surpassing GPT-5.5 for the first time since OpenAI's April launch. The model scores 88.6% on SWE-bench Verified and 74.6% on Terminal-Bench 2.1, beating GPT-5.5 across at least 12 benchmarks including most knowledge-work, coding, agentic tool-use, and long-context evaluations.

The headline feature is **dynamic workflows**, a new research preview capability in Claude Code that allows Opus 4.8 to plan large-scale tasks and then spawn hundreds of parallel subagents in a single session. This enables codebase-wide migrations across hundreds of thousands of lines of code, with Claude verifying outputs before reporting back. Early testers at Cursor, Devin, and Databricks report that Opus 4.8 catches its own mistakes more effectively — Anthropic's evaluations show it is roughly four times less likely than Opus 4.7 to let code flaws pass unremarked.

Anthropic also shipped effort control across all claude.ai plans, letting users dial thinking depth from fast to max, and a Messages API update allowing system directive injection mid-conversation without breaking prompt cache. Pricing remains unchanged at $5/$25 per million tokens (input/output), while fast mode is now three times cheaper than for prior models.

**Why it matters:** Claude Opus 4.8 represents a step change in agentic AI reliability — the combination of honesty about uncertainty, parallel subagent orchestration, and sustained long-context reasoning makes it the strongest general-purpose model for autonomous software engineering and enterprise agent workflows.
