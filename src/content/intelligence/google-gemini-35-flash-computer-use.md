Google DeepMind announced on June 24 that computer use is now a native, built-in tool in Gemini 3.5 Flash — the company's fastest frontier model. Previously available only as a separate standalone model, computer use is now deeply integrated into the main Flash inference path, allowing developers to build custom agents that can interact across browser, desktop, and mobile environments within a single API call. The model delivers approximately 1,500 tokens per second in output — roughly 4× faster than competing frontier models — making it purpose-built for latency-sensitive agentic workflows where dozens of sequential decisions compound into real-world delays.

The capability arrives alongside Google's broader Gemini 3.5 model family rollout, which began at Google I/O 2026 in May. Flash now outperforms Google's own previous flagship on agentic coding and reasoning tasks while being faster and cheaper — a rare inversion of the traditional speed-versus-quality tradeoff. Google has also released two optional enterprise safeguard systems: an explicit user confirmation gate for sensitive or irreversible actions, and an automatic stop mechanism for detected indirect prompt injections.

Early enterprise customers are already deploying 3.5 Flash with computer use for continuous software testing, cross-platform form filling, and enterprise automation. The model is available via the Gemini API and the new Gemini Enterprise Agent Platform.

**Why it matters:** By making computer use a first-class built-in capability at industry-leading speed, Google is lowering the barrier for building production-grade autonomous agents — and raising the stakes for competitors racing to define the agentic AI platform of 2026.
