### 6. LLM Evaluation and Feedback Platform

<div class="tab-content" data-tab="technical">

**Client:** Dom Rock

Developed an AI-powered web platform designed to compare responses generated by different Large Language Models (LLMs), evaluate their quality using predefined criteria, and collect human feedback to support Reinforcement Learning from Human Feedback (RLHF) workflows.

**Key Responsibilities:**
- Developed frontend features using Vue 3
- Built backend APIs with Python and FastAPI
- Integrated multiple Large Language Models for comparative analysis
- Utilized LangChain to orchestrate AI workflows
- Implemented vector-based storage and retrieval using ChromaDB
- Managed application data and feedback records with MongoDB
- Contributed to the definition of evaluation metrics and quality assessment processes for AI-generated responses

**Technologies:** Vue 3, Python, FastAPI, LangChain, ChromaDB, MongoDB, Generative AI, RLHF

</div>

<div class="tab-content" data-tab="non-technical" style="display:none">

**Client:** Dom Rock

Imagine a judges' panel for AI chatbots. When you have multiple AI models (like ChatGPT, Claude, etc.) answering the same question, this platform helps you figure out which one gives the best answer. It scores them on quality, compares their responses side by side, and collects human feedback — similar to how you'd compare several candidates in a job interview to pick the best one.

**What I did:**
- Built the user interface where evaluators compare AI responses
- Created the backend APIs that connect to different AI models
- Used LangChain (a framework for AI workflows) to orchestrate everything
- Set up a vector database to store and retrieve AI knowledge
- Helped define how to measure response quality

**In simple terms:** A platform that lets you pit different AIs against each other, compare their answers, and pick which one performs best — like a talent show for language models.

</div>
