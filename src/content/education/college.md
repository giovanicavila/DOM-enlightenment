## Overview

Degree in Systems Analysis and Development with hands-on experience in collaborative projects with technology companies.

**Key technical competencies and activities:**
- Development of web systems and applications using modern frameworks (e.g., React, Node.js, React Native)
- Implementation of Machine Learning pipelines, including data preprocessing, training, validation, and model deployment
- Application of Artificial Intelligence techniques for automation, classification, prediction, and data analysis
- Experience with RAG (Retrieval-Augmented Generation), integrating language models with search engines and knowledge bases
- Use of relational and NoSQL databases, data modeling, and query optimization
- Adoption of software engineering practices: versioning (Git), automated testing, continuous integration and delivery (CI/CD)
